What This Tool Is For

Maintain the kiosk gallery

Use this app to build and maintain the gallery of web destinations shown on the Innovation Studio Chromebase kiosks.

  • A card title
  • An author name
  • A public destination URL
  • A preview image URL
  • An optional QR code toggle
  • A QR image URL
  • A short description

The app also stores idle reset timing, return hotkeys, backdrop colors, and import/export data for handoff between workstations.

The Collection Editor panel also controls launch button color and the main gallery text scales.

Unlock The Editor

Hidden hold gesture

  1. In gallery view, press and hold the subtitle text above the gallery title.
  2. Hold for about 2 seconds.
  3. The app will switch to the editor and show an unlock countdown.
  • Select Relock when you are done.
  • If the timer expires, the app returns to gallery mode automatically.

Update A Gallery

Card workflow

  1. Unlock the editor.
  2. Work from the Gallery cards panel.
  3. Select an existing card or choose Add Card.
  4. Use Edit to open the card editor.
  5. Edit the card fields, including an optional preview image URL and the QR code checkbox for gallery cards.
  6. Use Preview In Kiosk to test the live destination.
  7. Use Done Editing to close the card editor.

Import And Export

Move or restore a collection

  • Export downloads the current collection as JSON.
  • Import loads a previously exported JSON collection.
  • Restore Sample replaces the current collection with the sample set.

Changes save automatically in this browser on this machine. Export the collection if you need a backup or want to move it to another workstation.

On a kiosk running in kiosk mode, changes are not saved locally. Update the published collection JSON and redeploy instead.

Collections And Kiosks

Point a kiosk at a collection

One deployment can host more than one collection, and each has its own stable URL. A display kiosk can also be set to always show the latest published collection.

Named Collections

Choose a collection by URL

  • The default collection loads at the plain gallery URL.
  • Add ?collection=slug to load a named collection.
  • Each named collection lives at public/data/<slug>.json in the deployment.
  • If a collection is missing, the app loads the default collection and shows a notice.
https://technobotanist.github.io/IS-WebKiosk/?collection=sample-showcase

Kiosk Mode

Always follow the published copy

  • Add ?kiosk=1 to turn kiosk mode on (?kiosk=0 turns it off).
  • The machine always loads the published collection and does not save local edits.
  • The setting is remembered on that machine, so you only add it once.
https://technobotanist.github.io/IS-WebKiosk/?collection=main&kiosk=1

To provision a new kiosk in one step, open a single link that names the collection and turns on kiosk mode. A shortened link can point to that address, so kiosks are configured by opening one short URL.

Gallery Mode

Visitors see the collection grid. Selecting a card opens the destination URL inside the kiosk viewer. Idle reset and return hotkeys send the session back to the gallery grid.

Troubleshooting

If the editor does not open, hold the subtitle text slightly longer and make sure you are not clicking a gallery card. If changes disappear, re-import the last exported collection JSON.
